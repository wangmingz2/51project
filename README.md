# 自动售货机设计（51 单片机）

基于 51 单片机的自动售货机课程设计，包含 Proteus 仿真、Keil C 源码与硬件制作详解。

## 目录结构

| 目录 | 说明 |
| --- | --- |
| `proteus仿真/` | Proteus 原理图与仿真工程（shj.DSN / shj.PWI） |
| `程序/1程序C语言/` | Keil C51 工程源码（shj.c / shj.uvproj）与编译固件 shj.hex |
| `程序/源程序.txt` | 源码备份 |
| `制作详解/` | 各元器件的原理图、接线与焊接方法图文说明 |
| `材料清单.xls` | 元器件清单 |

## 快速开始

1. 用 Keil uVision 打开 `程序/1程序C语言/shj.uvproj` 编译，生成 `shj.hex`。
2. 用 Proteus 打开 `proteus仿真/shj.DSN`，双击单片机载入 `shj.hex` 运行仿真。
3. 按 `1.JPG` ~ `5.JPG` 中的实物图接线搭建。

## 说明

- 仓库中的 `.hex` 为已编译固件，可直接烧录或用于仿真。
- 元件参数与调试细节见 `制作详解/` 各子目录。
